## Task 2: Retrofit `CompiledUniverse` for multi-level support
**File:** `src/townlet/universe/compiled.py`

**Changes:**
- Remove legacy single-level/flat-pack fields tied to `HamletConfig` (e.g., `hamlet_config`, `config_dir`, `environment_config`, `dac_config`, `drive_hash`) and their validations. Keep only what runtime still requires; v2.1 equivalents will be used in later phases.
- Add multi-level provenance/metadata fields:
  - `experiment_dir: Path | None = None`
  - `all_levels: dict[str, CompiledUniverse.LevelMetadata] | None = None`
- Add nested `LevelMetadata` dataclass (v2.1 DTOs):
  - `level_name: str`
  - `curriculum: CurriculumConfig`
  - `training: TrainingV2Config`
  - `observation_spec: ObservationSpec`
  - `action_metadata: ActionSpaceMetadata`
  - (Add per-level meter/affordance metadata if runtime needs them; decide now to avoid churn.)
- Add accessors:
  - `get_level(level_name: str) -> LevelMetadata` (ValueError if `all_levels` is None or missing level)
  - `available_levels -> list[str]` (sorted; empty if `all_levels` is None)
- Update `__post_init__`:
  - Keep tuple conversions where still relevant.
  - Drop hamlet_config-based meter/affordance count checks.
  - If `all_levels` is set, enforce non-empty dict.
- Update imports to include new types (CurriculumConfig, TrainingV2Config, Dict, Path).
