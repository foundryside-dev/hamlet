```markdown
### Configuration System

Training controlled via YAML configs in `configs/`. Each config pack is a directory containing:

```
configs/<experiment>/
├── experiment.yaml      # Experiment metadata and observation policy
├── stratum.yaml         # Stratum configuration (support/active pattern)
├── environment.yaml     # Environment-level vocabulary (meters, affordances, cascades)
├── actions.yaml         # Action space configuration
├── agent.yaml           # Agent configuration
└── levels/              # Curriculum levels
    ├── <level_name>/
    │   ├── curriculum.yaml    # Level-specific settings
    │   ├── bars.yaml          # Meter parameters
    │   └── affordances.yaml   # Affordance parameters
```

### Hierarchical Structure (v2.1)

**Experiment-level configs** (shared across all curriculum levels):
- `experiment.yaml`: Name, description, observation policy
- `stratum.yaml`: Substrate type, support/active vision settings
- `environment.yaml`: Meter/affordance vocabulary (WHAT exists)
- `actions.yaml`: Action space configuration
- `agent.yaml`: Network architecture settings

**Curriculum-level configs** (per-level under `levels/<level_name>/`):
- `curriculum.yaml`: Level metadata, substrate params, training params
- `bars.yaml`: Meter parameter values (HOW they behave)
- `affordances.yaml`: Affordance parameter values (HOW they work)

**Key Pattern**: WHAT (experiment) vs HOW (curriculum) - vocabulary is breaking change, parameters are not.
```
