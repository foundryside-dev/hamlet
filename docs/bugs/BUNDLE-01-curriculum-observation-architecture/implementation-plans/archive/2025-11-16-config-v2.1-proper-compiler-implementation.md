## Executive Summary

**Problem**: The previous plan "accidentally forgot to implement the compiler" - it created a separate v2.1 path that:
1. Only implemented stages 1-2 and 5 (skipped 3-4, 6-7)
2. Created `CompiledUniverseV21` (dual-path architecture)
3. Skipped symbol table resolution and cross-validation
4. Created technical debt through backwards compatibility layers

**Solution**: Properly implement the full 7-stage compiler by **reusing ALL existing compiler infrastructure** from the legacy flat-config compiler, adapting only Stage 1 (loading) to handle hierarchical structure.

**Key Insight**: The existing compiler is **architecturally excellent** (per superpowers:code-reviewer). We need to:
- Keep ALL 7 stages intact
- Replace ONLY Stage 1's file loading logic
- Use the SAME `CompiledUniverse` output (not a new v2.1 variant)
- Delete the backwards compatibility auto-detection code

**Estimated Effort**: 6-8 hours (1 day)

**Files**:

**Key Design Principles**:
1. **Vocabulary Enforcement**: Validate that all curriculum levels use the same bars/affordances as `environment.yaml`
2. **No Defaults**: All fields must be explicitly specified
3. **Support/Active Pattern**: `stratum.yaml` declares what CAN exist, `curriculum.yaml` declares what IS active

```python
@classmethod
def from_experiment_dir(cls, experiment_dir: Path) -> "RawConfigsV21":
    errors = CompilationErrorCollector(stage="Stage 1: Load Hierarchical Configs")

    # Load shared configs
    experiment = ExperimentConfig.from_yaml(experiment_dir / "experiment.yaml")
    stratum = StratumConfig.from_yaml(experiment_dir / "stratum.yaml")
    environment = EnvironmentConfig.from_yaml(experiment_dir / "environment.yaml")
    actions = ActionsConfig.from_yaml(experiment_dir / "actions.yaml")
    agent = AgentConfig.from_yaml(experiment_dir / "agent.yaml")

    # Load all curriculum levels
    levels_dir = experiment_dir / "levels"
    if not levels_dir.exists():
        errors.add(
            f"Missing levels/ directory in {experiment_dir}",
            code="MISSING_LEVELS_DIR",
            location=str(experiment_dir)
        )
        errors.check_and_raise()

    levels = {}
    env_meter_names = {m.name for m in environment.meters.meters}
    env_affordance_names = {a.name for a in environment.affordances.affordances}

    for level_dir in sorted(levels_dir.iterdir()):
        if not level_dir.is_dir():
            continue

        level_name = level_dir.name

        # Load all 4 curriculum-level configs
        curriculum = CurriculumConfig.from_yaml(level_dir / "curriculum.yaml")
        bars = BarsConfig.from_yaml(level_dir / "bars.yaml")
        affordances = AffordancesConfig.from_yaml(level_dir / "affordances.yaml")
        training = TrainingConfig.from_yaml(level_dir / "training.yaml")

        # VOCABULARY VALIDATION: Enforce WHAT vs HOW split
        level_meter_names = {b.name for b in bars.bars}
        level_affordance_names = {a.name for a in affordances.affordances}

        if level_meter_names != env_meter_names:
            missing = env_meter_names - level_meter_names
            extra = level_meter_names - env_meter_names
            errors.add(
                f"Meter vocabulary mismatch in {level_name}/bars.yaml\n"
                f"  Expected (from environment.yaml): {sorted(env_meter_names)}\n"
                f"  Actual: {sorted(level_meter_names)}\n"
                f"  Missing: {sorted(missing) if missing else 'none'}\n"
                f"  Extra: {sorted(extra) if extra else 'none'}",
                code="VOCABULARY_MISMATCH",
                location=f"{level_name}/bars.yaml"
            )

        if level_affordance_names != env_affordance_names:
            missing = env_affordance_names - level_affordance_names
            extra = level_affordance_names - env_affordance_names
            errors.add(
                f"Affordance vocabulary mismatch in {level_name}/affordances.yaml\n"
                f"  Expected (from environment.yaml): {sorted(env_affordance_names)}\n"
                f"  Actual: {sorted(level_affordance_names)}\n"
                f"  Missing: {sorted(missing) if missing else 'none'}\n"
                f"  Extra: {sorted(extra) if extra else 'none'}",
                code="VOCABULARY_MISMATCH",
                location=f"{level_name}/affordances.yaml"
            )

        levels[level_name] = CurriculumLevelConfigs(
            curriculum=curriculum,
            bars=bars,
            affordances=affordances,
            training=training
        )

    if not levels:
        errors.add(
            f"No curriculum levels found in {levels_dir}",
            code="NO_CURRICULUM_LEVELS",
            location=str(levels_dir)
        )

    errors.check_and_raise()

    return cls(
        experiment=experiment,
        stratum=stratum,
        environment=environment,
        actions=actions,
        agent=agent,
        levels=levels,
        experiment_dir=experiment_dir
    )
```

**Challenge**: Existing stages expect a single `HamletConfig` with all settings, but v2.1 has:

@dataclass(frozen=True)
class RawConfigsV21:
    """Container of all config DTOs for v2.1 hierarchical structure."""

    # ... existing fields ...

    def to_legacy_format(self, level_name: str) -> RawConfigs:
        """
        Convert v2.1 hierarchical configs to legacy RawConfigs format for a specific level.

        This allows reuse of existing compiler stages 2-7 without modification.

        Args:
            level_name: Which curriculum level to compile (e.g., "L1_full_observability")

        Returns:
            RawConfigs instance that existing compiler stages can process
        """
        if level_name not in self.levels:
            available = list(self.levels.keys())
            raise ValueError(
                f"Level '{level_name}' not found. Available: {available}"
            )

        level = self.levels[level_name]

        # Merge hierarchical configs into flat HamletConfig structure
        # This is the ONLY place where we "flatten" the hierarchy
        hamlet_config = HamletConfig(
            training=level.training.training,
            environment=level.training.environment,
            population=level.training.population,
            curriculum=level.curriculum,
            exploration=level.training.exploration,
            bars=tuple(level.bars.bars),
            cascades=tuple(level.bars.cascades) if hasattr(level.bars, 'cascades') else tuple(),
            affordances=tuple(level.affordances.affordances),
            cues=self._build_cues_config(),  # From agent or environment
            substrate=self.stratum.substrate,
        )

        # Create RawConfigs instance
        return RawConfigs(
            hamlet_config=hamlet_config,
            variables_reference=self.environment.vfs_variables.variables,
            global_actions=self.actions.global_actions,
            action_labels=self.actions.action_labels,
            environment_config=self._build_environment_config(level),
            source_map=self._build_source_map(level_name),
            config_dir=self.experiment_dir / "levels" / level_name,
        )

    def _build_cues_config(self) -> CuesConfig:

        from townlet.config.cues import CuesConfig

        return SourceMap(
            experiment=str(self.experiment_dir / "experiment.yaml"),
            stratum=str(self.experiment_dir / "stratum.yaml"),

            actions=str(self.experiment_dir / "actions.yaml"),
            agent=str(self.experiment_dir / "agent.yaml"),

            affordances=str(level_dir / "affordances.yaml"),

## Appendix B: Understanding WHAT vs HOW Split

**WHAT (Breaks Checkpoints)**:
- `environment.yaml` defines vocabulary (meter names, affordance names)
- Changing vocabulary changes observation/action space dimensions
- Incompatible with existing checkpoints

**HOW (Preserves Checkpoints)**:
- `levels/*/bars.yaml` defines meter parameters (depletion rates, thresholds)
- `levels/*/affordances.yaml` defines affordance parameters (effects, costs)
- Changing parameters changes dynamics but not network architecture
- Compatible with existing checkpoints (though behavior differs)

**Enforcement**:
- `RawConfigsV21.from_experiment_dir()` validates vocabulary consistency
- All levels must have same meter names as `environment.yaml`
- All levels must have same affordance names as `environment.yaml`
- Error if any level adds/removes meters or affordances

**Benefits**:
- Enables checkpoint transfer across curriculum levels
- Clear boundary between architecture-breaking and parameter changes
- Prevents accidental checkpoint incompatibility

---

## Appendix C: Support vs Active Pattern

**Support (Stratum)**:
- `stratum.yaml` declares which observation fields CAN exist
- Example: `vision.support: both` means both global and partial vision supported

**Active (Curriculum)**:
- `levels/*/curriculum.yaml` declares which fields ARE active
- Example: `active_vision: global` means global vision active, partial masked

**Implementation**:
- Observation spec includes ALL supported fields
- Masked fields filled with zeros (enables transfer learning)
- All levels have same `obs_dim` (network architecture unchanged)
- Only difference: which fields are zeros vs real values

**Example**:
```yaml
# stratum.yaml (declares support)
vision:
  support: both  # Can use global OR partial

# L1/curriculum.yaml (global active)
active_vision: global  # Uses global, partial masked

# L2/curriculum.yaml (partial active)
active_vision: partial  # Uses partial, global masked
```

Both L1 and L2 have same `obs_dim`, enabling checkpoint transfer!
