gated this on measuring whether effects overshoot `1.0`. They do, routinely, and config alone
proves it: bars ship `initial: 1.0` with `bounds.max: 1.0`, while `SLEEP` applies
`energy = energy + 0.8` (computes **1.8**) and `EAT` applies `satiation + 0.4` (computes **1.4**).
`torch.clamp` is currently the **only** thing re-ceilinging them.

Two corrections follow:
1. **There are FOUR meter-clamp sites, not six** — `affordance_engine.py:209`, `:310`,

   instruction is over-counted.
2. **Deleting the clamp at `:209` alone is not a cleanup — it removes the only enforcement of a

**Discounted, on policy.** Systems proposed retaining `torch.clamp` as a silent safety net. Rejected

## 1. What this fix set achieves

Seven units close the defects that would otherwise be **frozen into the oracle** by the strangler rewrite (PDR-0006): a compile cache that returns another level's identity, per-level content hashes computed and never compared, a `brain_hash` that hashes a config the run never uses, a live-inference server that applies any checkpoint from any universe with no identity check at all, a recurrent training path whose LSTM weights receive exactly zero gradient, Q-targets that treat every sampled-window boundary as terminal, an interaction gate that ignores every non-money declared cost, and four red quality gates. Freezing before these land makes each one a *requirement* of the rebuilt system — and for the provenance defects specifically, the damage is to artifact identity, which is the currency an oracle-based rewrite trades in. Landing them unblocks the freeze: after this set the compile cache returns the projection you asked for, the four per-level content hashes plus an effective `brain_hash` are stamped into every checkpoint and hard-compared on resume, the serving path routes through the same guard chain as training, recurrent training actually trains its recurrent weights and bootstraps at window boundaries, declared costs gate interactions, and ruff/black/mypy/pytest are green. Every unit carries at least one pinning test that fails before and passes after — the absence of exactly that kind of test is why six declarative features shipped inert.
