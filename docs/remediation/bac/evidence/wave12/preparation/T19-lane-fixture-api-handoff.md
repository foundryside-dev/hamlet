## Explicit external stop semantics already present

POP exposes **`flush_episode(agent_idx: int, reason: RunnerCompletionReason) -> EpisodeCompletion|None`**. Its inspected implementation finalizes the existing nonempty lane without changing replay done. RunnerCompletionReason/EpisodeCompletion are imported from `townlet.training.episode`; that module's declaration was not read here. Source-visible runner calls use cap, budget, shutdown and checkpoint reasons. Once a lane is flushed, POP rejects another active transition in that completed lane; close all pending lanes before reset rather than step after an external completion. Reset explicitly refuses unfinished nonempty lanes.
