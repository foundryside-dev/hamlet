## VFS seed/episode API: exact current facts

VR95–133 implements one environment-wide mutable pair, not per-world lifecycle records:

- `VFSRandomness(seed: int)` rejects bool/non-int with TypeError, masks the seed modulo2**64, and initializes `_episode=0` (98–102). Negative constructor seeds are accepted and masked. `.seed` and `.episode` expose the values (104–110).
- `reset() -> None` unconditionally increments `_episode` by1 (112–114). It accepts no identity/token, has no deduplication, and imposes no boundary/participation condition. Episode0 exists before the first reset; the first reset yields1. The Python counter has no explicit upper bound here.
- `state() -> dict[str,int]` returns a fresh exact `{"seed": self._seed, "episode": self._episode}` (116–118), with no schema tag, world roster, binding, closure or acceptance metadata.
- `restore(state)` requires exactly keys seed/episode; each must be a non-bool int >=0 (120–127). It validates both before either assignment, then masks seed modulo2**64 and assigns episode unchanged (128–129). Oversized nonnegative seeds are accepted/masked; negative restore seeds refuse although the constructor accepts them. Ordinary expected key/value rejection precedes mutation in this method. This does not prove a parent checkpoint loader is atomic. The annotation is dict, with no explicit mapping-type check; arbitrary objects are not promised a uniform validation exception.
- `instant(*, tick, worlds, device)` constructs `DrawInstant(key=_instant_key(seed, episode, tick), worlds=worlds, device=torch.device(device))` without explicit tick/world type/range validation (131–133). `_instant_key`85–86 masks seed/tick and mixes episode. This reads state; it does not increment episode or consume a Torch RNG generator.
- VR196–208 uses `torch.arange(shape[0])` as the numeric world key and deterministic integer mixing; `reference_uniform`89–92 explicitly takes `world: int`. World identity in these draws is current row index, not WS exact WorldId. `DrawStream` tracks an ordinal per stream instance (169,175–180); uniform/normal compute deterministic tensor arithmetic, not ambient random draws (204–218). The doc's batch-size independence applies to an unchanged numeric row/world argument; it is not evidence of stable-ID invariance under lane reordering.

ENV588 constructs this object from `torch.initial_seed()` once. Ambient RNG consumption alone does not alter its captured seed or VR's pure draw formula. ENV1284–1294 exposes `_vfs_draws()` with current global tick/count/device, `vfs_random_state()` delegating to `.state()`, and `restore_vfs_random_state(state)` delegating to `.restore(state)`. ENV828 invokes the unconditional VFS increment **after** layout/positions/meters/clock/effect/history mutations, and **before** item reset/evaluation/spawn/final observation. Thus a late reset exception after828 has already advanced VFS episode, whereas an earlier failure need not have. No accepted-episode guard reconciles that distinction. A repeated reset increments again. Current VFS serialization is not an accepted episode checkpoint contract.
