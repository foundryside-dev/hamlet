# Public disposable WorldRNGState custody API

Root verified unchanged WS871 at a7c4cd0b, SHAa639d6f927492cf0334a49f330f514b6472be75f624f24a2f1b5e8381af93b2c. Public API/data capsule only; actual PW07 four-source contexts must not read WS implementation.

Module townlet.exploration.world_curiosity_state exports WorldRNGState and WorldCuriosityDescriptor. Exact constructor entry: WorldRNGState.create(*, descriptor: WorldCuriosityDescriptor, world_id: str, cuda_devices: tuple[int, ...]) -> WorldRNGState. All arguments required. Use actual already-validated private receiving descriptor and an exact declared target WorldId; a shared descriptor refuses. cuda_devices is the explicit canonically sorted unique tuple of used indices, empty tuple for CPU. CPU owners do not query/initialize CUDA. Nonempty devices require already initialized available devices at the quiescent runtime boundary; no hidden initialization/guessing.

create is a quiescent, serialized operation using owned local seeded generators; it does not consume ambient global random streams. Named components are exactly model_init, target, predictor, service. Each state is a distinct mutable owner; create a separately disposable owner, not a production target world's RNG reused for validation.

Exact public context manager: rng.activate(component: str) -> Iterator[WorldRandomSources]. Use with rng.activate('model_init') around the actual shared make_backend(..., rng=None, descriptor=the factory's required shared value) construction/disposable native work as needed. This supplies actual private ambient custody while keeping the shared factory's rng=None contract. The disposable owner is bound to a legitimate target private descriptor/ID but its advanced streams are discarded; it is not the production candidate's future RNG. Public yielded sources have python and numpy handles; no yielded value is required for a constructor using ambient Torch draws.

Activation serializes the ambient stream swap, captures/restores Python random, NumPy legacy and the named PCG generator, Torch CPU and explicitly used CUDA states. Normal and exceptional exit preserve ambient streams while advancing only that owner's named component. Same-owner nested components are supported; same-component reentry shares the active stream. Cross-owner nested activation refuses. create/snapshot/owned lifecycle preparation must occur at a quiescent point; do not construct a disposable owner inside another owner's active domain. Restoration failure marks owner/coordinator unusable and raises; do not pretend successful rollback or bypass quarantine semantics.

Actual native validation/loading and factory/RNG allocation still follow outer allocation admission and genuine parent custody. This API is not authorization to replace actual backend validators, share private target RNGs, use an always-success validation callback, or run ad-hoc imports during the frozen qualification barrier.
