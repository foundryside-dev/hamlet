2. **Ordinary NONE native validation.** `CP.validate_native(provider, payload, *, policy, descriptor)` (curiosity_checkpoint.py:946) branches on family='none', requires exact keys `{epsilon, epsilon_decay, epsilon_min}`, finite numbers, exact selected decay/end and epsilon within selected bounds. Ordinary load must still retain these values exactly and preserve the existing strict finite validation contract.
3. **Shared checkpoint/restore clone.** BANK.checkpoint_state calls the shared provider's checkpoint_state and CP.capture_gradients. BANK.prepare_restore calls `CP.clone_provider(self._shared, family=self.policy.strategy)`, CP.validate_native, native load_state, exact checkpoint_state roundtrip and attach_gradients (scoped_curiosity.py:1160). CP.clone_provider (curiosity_checkpoint.py:936) uses `deepcopy(provider, memo)`; only count_based/ICM get explicit ResolvedExplorationPolicy memo reconstruction. NONE uses ordinary deepcopy. There is no consumer conversion back to EPS. The genuine subclass must remain deepcopy-compatible; custom subclass copy/reduction behavior is outside this capsule.
4. **Private owned clone/restore.** `OwnedWorldBackend._clone_backend` reconstructs an attached actual ResolvedExplorationPolicy through its portable ABI when present, then deep-copies the backend (world_curiosity_state.py:769). It does not reconstruct by EPS class or strategy name. `_backend_contract` checks only checkpoint_state/load_state callability. Private prepare_restore uses supplied actual factory candidate and CP validation, native load, exact roundtrip, then another clone. Thus actual native subclass and its new prepared/reset handles must obey existing copy/owned-state contracts without changing ordinary checkpoint data. This capsule does not qualify those new handle implementations.
