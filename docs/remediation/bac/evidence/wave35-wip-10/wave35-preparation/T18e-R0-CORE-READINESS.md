## Producer API proposal to freeze before consumers

The following names are proposed for implementation in the two authorized core source paths. Final implementation/review must publish any exact signature correction before BANK adopts it. Keep ordinary existing seed/sampling and generator ownership semantics. No new persistent process RNG checkpoint schema or cohort restore promise is introduced.

`rng_custody.py` owns a single process custodian, obtained by `process_rng_domain() -> AmbientRNGDomain`. Production owners cannot select a second independently usable admission domain. Test isolation resets only inert test-owned registrations under exclusive idle custody, or uses a fresh process for poison cases; no test reset can heal production poison.

Proposed public domain interface:

```python
register(*, owner: object, cuda_devices: tuple[int, ...],
         entrypoints: frozenset[str]) -> RNGParticipant
unregister(*, participant: RNGParticipant) -> None
operation(*, participant: RNGParticipant, operation_kind: str,
          lineage: RNGOperation | None) -> ContextManager[RNGOperation]

              operation: RNGOperation) -> RNGCurrentToken
validate_current(*, token: RNGCurrentToken,
                 operation: RNGOperation) -> None
poison(*, operation: RNGOperation, error: BaseException) -> None
```

Registration binds actual stable owner identity, explicit sorted device inventory and permitted entrypoints; duplicate/foreign/stale membership refuses. Register/unregister/inventory change requires exclusive idle custody and advances generation. Registering a label without consulting it at execution closes nothing. Participant, operation and current-token objects are producer-issued opaque identities with identity equality, creator process/thread binding where applicable, and no pickle/deepcopy/portable authority. Validate an issuance record plus exact identity; merely manufacturing an object with matching fields must not work.

Top-level operation passes lineage=None. Other enrolled threads block at admission before factory/callback/capture effects. Same-thread entry with lineage=None while an operation is active refuses before effects. A nested producer must pass the exact active operation, on its issuing thread, within its active synchronous lifetime, with a registered permitted participant/entrypoint. A token from another domain/thread, expired operation or unrelated lineage refuses. Domain operation exceptions conservatively advance revision; success also advances revision even if bytes were unchanged. Poison prevents subsequent capture/swap/ordinary operations. Generation/revision are not inferred from RNG equality.

Preserve RND's current `rng.activate(component)` signature: genuine same-RNG named activation inherits only the already-authenticated active frame's exact operation, maintaining model_init→target/predictor and A→B→A. It cannot adopt an unrelated active operation merely because it runs on the same thread.
