## Selected draw and continuation facts

* Flat `sample` and `sample_batch` both call `_indices`, which invokes `torch.randperm(self.size, device=self.device)`. This is an ambient Torch generator draw on the selected device. `sample` is the direct dictionary adapter; qualified `sample_batch` emits a receipt and requires captured legality/readiness. The source provides no owner-local Torch generator.
* PER direct `sample` calls `per_sampling.sample_legacy_float32_units` regardless of configured `_sampler`; `_draw`/qualified `sample_batch` with `_sampler.rng is None` calls `per_sampling.sample_legacy_units`. The source docstring identifies the direct path as global NumPy successive sampling. Exact internal draw count and rejection behavior of these unread helpers remain unknown. Qualified `sample_batch` with an owned `_sampler.rng` instead calls `per_sampling.sample_units(..., rng=self._sampler.rng, mode=self._sampler.mode)`.
* `configure_sampling` clones the supplied NumPy Generator state, without advancing that caller generator, into `_sampler`; supported engine names are PCG64, PCG64DXSM, MT19937, Philox, SFC64. `serialize` records `sampling_mode`, origin/objective/weight rule and `sampling_rng` ownership, engine and deep-copied state. Validation/restoration reconstructs an off-side generator and `load_prepared` clones it again. This continuation belongs to this PER buffer, not ambient transport.
* Recurrent direct `sample_sequences` uses `random.choices` for episode and `random.randint` for start. Configured uniform `sample_batch` uses Python `random.choices`/`randint` for the legacy adapter or `random.choice(windows)` otherwise. These are ambient Python-stream calls. Configured prioritized `sample_batch` clones `_priority.rng`, calls `per_sampling.sample_units(..., rng=clone)`, then publishes the advanced clone in `_priority` only after batch packing. `_support` draws only on a clone when refreshing a domain; no visible ambient call there. Exact helper internals remain unread.
* `for_prioritized_replay` clones the explicit caller generator; priority transport encodes its generator state in `priority_state`, decodes/restores it, and preserves current priority config and window/unit identity. `set_vector_tick`, captured storage, priority updates and sample publication mutate the same replay owner. They need same-owner exclusion even where their selected region is ambient RNG free.

All three classes expose mutable public storage: flat/PER tensor fields and ring counters; PER additionally public `priorities`, `unit_ids`, beta and configuration; sequence public `episodes` deque and counters, with each episode a dictionary of tensors. Internal `_sampler.rng`, `_priority.rng`, priority domains and archives are additional owned mutable references. A caller retaining raw aliases can mutate outside methods; the public core contract gives no automatic alias detector. Existing source contains no `process_rng_domain`, replay participant, operation lineage, owner lock, revision, poison or native preparation currentness check. The restore candidates are validated data, not issuer-bound one-use R0 handles.

## Required interface reconciliation

The public core contract supplies `process_rng_domain().operation(participant=..., operation_kind=..., lineage=...)` and a registered weak owner/explicit CUDA inventory; explicit `None` is standalone admission and exact active lineage is needed for nested work. Replay currently has no participant or lineage parameter. Parent/root must settle the exact registration signature, operation kinds, current-lineage transport to POP/BANK callers, device inventory and same-owner lock API from the core owner before source writing. An unverified guessed signature would risk bypassing the sole domain. The smallest supported seam is one replay-owned admission helper used by each actual draw entrypoint, plus same-owner exclusion around all replay mutations, capture and publication. Preserve each selected sampler and its current RNG transport, including direct adapters; no seed substitution or POP-only gate.
