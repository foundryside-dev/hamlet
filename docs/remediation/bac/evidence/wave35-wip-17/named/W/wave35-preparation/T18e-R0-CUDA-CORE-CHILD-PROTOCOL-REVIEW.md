The proposed control uses genuine inheritance: the qualified spawn child enters each real gate and forks with that live scope and actual domain exclusion held. Separate admission/local fork trials avoid assuming an undocumented nested-gate composition. The grandchild receives the actual inherited domain, participant and live gate; it neither patches PID nor fabricates a replacement domain/token. Its observed PID must differ from the retained issuing PID, which must match its actual spawn parent. This directly tests the required process boundary.

The guard-only boundary is appropriately narrow. The spawn parent precreates devices, fixtures, descriptors and probes; actual `/proc/self/task` count1 is required immediately before fork. The grandchild uses inherited guard calls and standard-library evidence/pipe operations, without imports, Torch/NumPy/CUDA calls, RNG snapshots, queue/pytest cleanup or ordinary context-manager unwinding. `os._exit` avoids unwinding the inherited parent scope. Source-qualified transparent probes must establish that a refused guard did not reach a lock or CUDA seam; “no actual GPU call” alone would not establish zero attempted CUDA access. Refusal of the OS single-thread prerequisite remains failed applicability/UNRUN evidence, never PASS. Configured interop5 is not proof of five live threads or proof of one live thread.

The custody chain is honest at the design level: full qualified spawn identity stays distinct from the nested guard-only profile; the latter reports actual PID/PPID, inherited module paths/file hashes, actual task count, explicit null Torch profile and measured guard outcomes. Actual fork return, waitpid, pipe acknowledgement and child-owned identity must agree. The parent observes rather than manufactures identity. Exact bounded payloads, total deadline, exit-status checks, exclusive artifacts and owned cleanup prevent absent/hung/signalled children from becoming success receipts. After both trials, actual spawn-parent health/ambient preservation and pytest-parent preservation remain required.
