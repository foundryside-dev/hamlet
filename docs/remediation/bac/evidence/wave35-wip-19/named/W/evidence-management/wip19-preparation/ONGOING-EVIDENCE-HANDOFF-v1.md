## Each next finite update

1. Root names the newly closed round interval and supplies exact candidate manifests, resource preflights, authoritative check records, applicable grants/rulings, frozen report seals and completed reviews. Keep an active round out of the closed component.
2. Inventory only that interval's complete `Q/wave35-rN-*` top-level namespace and recursive descendants, including empty directories. Bind each actual command result separately to its own candidate/base/manifest, exact spec, log and custody witnesses. Preserve capture failures, mixed directories, failed attempts, unrun templates and retries. Never turn absent results into PASS.
3. Add only named causal dependencies outside the interval. Link prior immutable components and their objects rather than copying their historical blobs or recursively importing old waves. Group content by SHA256 while retaining every alias. Distinguish published reuse from prepared-but-unpublished reuse; the future authenticated selector makes the final object decision.
4. Freeze an exact inert report snapshot only if no matching immutable snapshot already exists. Record expected hash before reading a mutable report and reject mismatch. Do not treat current REPORT.md as an immutable reference. Preserve source deltas only as inert artifacts tied to exact base/candidate identities; never execute copies.
5. Write new exclusively created inventory/component/metadata-check versions under this preparation directory. Rehash selected inputs and verify closed namespace equality. Return paths, SHA256, finite coverage and material gaps to root; detailed bookkeeping stays in artifacts. If inputs change, create a linked new version with a reason, never overwrite v1.
6. Append a completed later source review as a separate hash-bound supplement. It must identify exact reviewed candidate and scope; no inference from a running review or substitution for final terminal independence. If the review changes the next implementation plan, retain both failure and repair history.
