## Exact archive storage and metadata-only access — existing source facts

`HistoricalReplayArchive` is a frozen, slotted dataclass deriving from `_Owned` (H265–304). Its six stored slots are `source_formats: Mapping[str, object]`, `original_state: Mapping[str, object]`, `source_digest: str`, `archived_row_count: int`, `reward_semantics: str`, and `approval_reference: str`. The two Mapping annotations do not mean proxy/frozen mappings. Post-init `_own` (H273–275, H296) replaces both slots with recursively cloned values through `object.__setattr__`. `_clone` (H51–62) creates detached tensor clones, new OrderedDicts for OrderedDict inputs, new builtin dicts for other Mapping inputs, new lists and tuples recursively, and uses `copy.deepcopy` otherwise. Thus ordinary successfully constructed archives own mutable containers and tensor storage independent of the ordinary constructor inputs; frozen dataclass protection does not freeze the nested objects. The source performs ownership copying, not read-only proxy construction. Tensor values remain on their existing devices; clone may therefore launch CUDA work.

Every ordinary `archive.original_state` or `archive.source_formats` access invokes `_Owned.__getattribute__` (H268–270), retrieves the slot using `object.__getattribute__`, then calls `_clone` again. This is a full recursive copy, not metadata access. Even post-init reads at H297 copy again before local validation/digest; validation includes tensor finite/negative reductions (H169–195), and digest explicitly transfers tensor values to CPU (H83–88). Archive construction, public reads, query_rows, encode/decode/reconstruction and export are therefore unsuitable as a metadata-only pre-inventory operation when their CUDA work must be covered first.

For an **exact canonical `HistoricalReplayArchive` instance**, `object.__getattribute__(archive, "original_state")` and the analogous `"source_formats"` access bypass `_Owned.__getattribute__` and directly return the already stored slot objects. There is no property/getter descriptor for either slot in this class, and these accesses do not call `_clone`, validation, digest, export, or a project helper. This is an available internal source fact, not a new public method. `object.__getattribute__` generally still honors descriptors; this conclusion is about the exact class's ordinary slots, not arbitrary subclasses with replacement descriptors or arbitrary user objects.

An internal inventory implementation can use that direct stored reference transiently to enumerate ordinary containers and read ordinary tensor device metadata without copying/exporting tensor values. It must not return the mapping or tensor references to a caller, mutate them, call archive constructors/encoders/query_rows/export, or obtain them through the clone-on-read attributes. Returning only device metadata would preserve the existing public ownership boundary. This statement establishes storage access feasibility; no traversal implementation, concurrency guarantee, or caller reachability was inspected here.
