CPU/NUMA/GPU topology text-or-null.
2. Recompute admitted cgroups facts with provenance exact discovery.json ref: quota unlimited(None,reason cpu.max is max), period measured, memory unlimited(None,reason memory.max is max), cpuset sorted list. Measured fact shape(state:measured,value,reason:"",provenance). Missing optional topology: state unsupported,value null,reason KEY not observed,provenance. All admission raw fact values and provenance must match, including competing_workloads,affinity,scratch,host/limited/current RAM,capacity; primitive bool must not equal integer.
