# T12 bounded archive-bearing inspection transport proposal

**PROPOSED for exact-artifact Astra MEDIUM review; production remains pinned and unchanged.** This reconciles the confirmed R1 P2 second-save loss. It is one additive transport, not a new design loop or a native-admission claim. The existing five-source task boundary remains SB/HC/RC/OP/counted regression; no helper/module or Python default argument is added. HC needs no further producer change for this repair.

## Concrete problem and required distinction

An unconfigured two-argument SB accepts old5 through approved Option A and owns complete archives, but its next public serialize returns bare5 without those records. Reload therefore loses original historical rows/digests. With newly authored legacy rows added, bare5 instead reclassifies those new rows as historical on reload while still dropping the original archives. The new counted causal test covers two distinct original histories, both empty and nonempty newly authored legacy transport, real torch-save/load at a relocated path, query/export, source ownership and a second resave.

Keep three existing meanings distinct: bare old5 is a pre-capture artifact imported through Option A; newly authored direct legacy transport has no declared A/qualified legality; captured6 has explicit geometry/options/masks and full active resume. The repair must not guess A/options, mark maskless rows captured, add fields silently to closed5/6, or label newly authored legacy rows `historical_recorded_pre_fix` merely to put them somewhere portable.

## One closed wire representation

Add an inspection envelope with **exactly four keys**:

| Key | Exact value/domain |
|---|---|
| `inspection_kind` | exact string `sequential_replay_inspection` |
| `inspection_version` | exact integer1, rejecting bool/float/unknown versions |
| `legacy_transport` | complete exact legacy sequential5 mapping, using the existing five-key/eight-field structural schema |
| `historical_archives` | list of the existing exact six-field HC archive records |

There is no outer replay `format_version`, action dimension, legality flag, ReplayOptions, invented source provenance or learner-readiness count. The tag explicitly describes inspection transport. The nested `legacy_transport` holds only the newly authored public legacy rows currently stored in the unconfigured object, with existing whole/fixed/length-weighted sampling and post-terminal dictionary masking. It is not an archival payload and never inherits historical reward provenance. Imported old rows exist only in `historical_archives` and retain their original source domain/digest/count/state/reward/approval fields.

Unconfigured `serialize()` with **no archives** keeps its exact existing bare5 representation, including empty5. Unconfigured `serialize()` with retained archives emits the envelope, whether its new legacy row population is0 or nonzero. It embeds complete owned archive records and an owned exact5 transport mapping, so relocation has no external-history dependency. A well-formed envelope may have an empty archive list, but the ordinary producer continues to choose bare5 when no history exists. Configured `serialize()` remains closed captured6, unchanged.

## Strict dispatch and installation

Dispatch inspection by the exact explicit tag/version before existing bare5/6 dispatch; no fallback guesses. An attempted inspection payload with wrong/missing/extra keys or an unsupported tag/version refuses as malformed inspection instead of being coerced into5/6. Existing bare5 and6 payloads retain their exact schema/version behavior.

Validate `legacy_transport` through the unchanged pure strict5 structural route, preserving original optional-component values and deliberate interior-terminal transport. Validate/reconstruct every six-field archive with the existing HC codec/domain digest and SB's sequential-kind/observation-width compatibility checks. Reuse existing canonical content comparison/dedup; preserve distinct domains and reject contradictions. Do not recalculate a new provenance domain or duplicate HC digest algorithms. Pure `validate_serialized` may add a dedicated owned validated-inspection subtype; its nested5 validation does not install data or advance RNG.

Prepare a dedicated inspection candidate off-side. Clone/detach/move the nested newly authored legacy transport into its legacy row container, retain legacy row counts and episode-count semantics, and merge complete validated incoming/target archives without dropping history. Keep `_configured=False`, `action_dim=None`, `replay_options=None` and qualified `retained_transitions=0`. Crucially, materializing a bare `_ValidatedLegacyState` must still archive/fresh0; only the validated explicitly tagged inspection container restores its separately designated new legacy transport. This prevents a public bare5 validated/materialized bypass of Option A.

Inspection restore is admitted to an unconfigured legacy destination. A configured captured destination cannot be silently downgraded or be given raw legacy rows as active6; reject that new inspection input before mutation with a located diagnostic directing inspection through the two-argument route. Existing bare5 import into configured replay remains approved-A archive/fresh0, and existing captured6 resume remains unchanged. This restriction concerns the new envelope type, not a previously accepted5/6 input. No previously supported load/save/store/sample capability is selected for loss or refusal.

All tensor/device allocation, complete validation, archive merging/dedup and ownership occur before installation. The live installer transfers one compatible prepared candidate and retains its existing target-history/no-downgrade guards; it does not perform fallible archive materialization or validation after any live field changes. Malformed envelope/source/late preparation failure leaves the populated target, source mappings, archives and RNG unchanged.

## Explicit mode semantics

Existing signatures stay callable auto adapters; additional mode-taking entry points retain required keyword-only `requested_mode`. No pseudocode default or whitelist relaxation is authorized.

For the new envelope on an unconfigured destination, `auto`, `inference` and `archived_history_fresh_episode` preserve the exact inspection transport plus archives. They never activate original archived rows or qualify the new raw rows for ReplayBatch. Qualified active retention/readiness remains0/unavailable; legacy `num_transitions`, stats, episode count and explicit public dictionary sampling describe only the newly authored legacy transport. The archival/fresh mode name does not authorize relabeling or discarding that transport. No learned-state/optimizer/RNG continuation or episode-local reset is claimed by this storage-only operation.

Explicit `recorded_full_resume` on the inspection envelope raises HistoricalLegalityUnavailable before mutation: there is no recorded qualified replay identity to restore. This does not remove current6 full resume;6 remains governed by its actual geometry/options/masks and cannot be rewritten or downgraded into inspection/old5. Bare5 recorded-full-resume refusal and its ordinary approved-A archive/fresh0 behavior remain unchanged.
