- severity: **P1** (silent data loss; wrong world at runtime)
- where: `src/townlet/universe/compiled.py:380-410` (`to_dict` all_levels block has no `items_appearance` key) and `:458-492` (`from_dict` never sets it; `LevelMetadata.items_appearance` defaults to `None` at `:255`); consumer `src/townlet/environment/vectorized_env.py:820` (`if self.item_manager is not None and self.level.items_appearance is not None: … spawn_initial_items`); callers that compile with the cache on by default: `src/townlet/demo/runner.py:154`, `src/townlet/demo/live_inference.py:304`.

The first DemoRunner run trains with apples/medkits/coins, the second (cache hit) trains without any items; a served checkpoint renders an item-less world. `_validate_compiled_token_coherence` does not cover it; `test_compiled_universe_round_trip_serialization` (tests/…/test_compiled_universe_serialization.py:140-162) checks only hashes/schemas.
- reproduction (`roundtrip_runtime.py`):
