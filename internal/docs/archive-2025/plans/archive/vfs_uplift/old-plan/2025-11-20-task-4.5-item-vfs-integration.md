**Goal:** Enable items to have their own VFS state (durability, freshness, etc.), self-modify via Effects, and expose item properties in observations.

**Architecture:** Items get `item`-scoped VFS variables (similar to `agent` scope). ItemManager allocates VFS slots for item state. Effects execution passes item's `vfs_index` as `self_index` to enable `self.vfs.durability` syntax. Observation system exposes item state for agents to see item properties (e.g., "apple has 80% freshness").

**Tech Stack:** VFS Registry (item scope), Effects System (ExecutionContext), Observation Builder (item VFS exposure)

**Dependencies:** Task 4 (Items System) complete

**Estimated Time:** 2-3 days (6 tasks)

## Context: What's Missing

Currently, items have a `vfs_index` but don't use it:
- Items can't have their own variables (durability, freshness, etc.)
- Items can't self-modify via Effects (`modify: self.vfs.durability -= 1`)
- Item properties aren't observable (agents can't see "rotten apple" vs "fresh apple")

**Current code:** `ItemActionHandler._execute_interaction()` passes `self_index=None` with comment:
```python
self_index=None,  # Items don't have self yet (Phase 4 limitation)
```

**Goal:** Remove this limitation by wiring item VFS state through the entire system.

---

## Critical Fix (Per Review Feedback)

**Original Gap:** The initial plan updated `ItemActionHandler` to pass `self_index` but missed updating `ExecutionContext` to handle item-scoped variable lookups. Without this, `self.vfs.durability` would fail with "Variable not found."

**Solution:** Task 4 now includes:
1. Add `self_is_item: bool` parameter to `ExecutionContext.__init__()` to track whether `self_index` refers to an item or agent
2. Update `ExecutionContext.get_path()` to route `self.vfs.*` lookups to item_vfs storage when `self_is_item=True`
3. Update `ItemActionHandler` to pass `self_is_item=True` when creating ExecutionContext

This ensures the Effects system knows to look in `item_vfs` registry when executing `modify: self.vfs.durability -= 10`.

```python
def __init__(
    self,
    variables: list[VariableDef],
    batch_size: int,
    device: torch.device | str,
    max_items: int = 0,  # NEW: Maximum items for item-scoped variables
) -> None:
    """Initialize VFS registry with storage tensors.

    Args:
        variables: Variable definitions from schema
        batch_size: Number of agents (batch size)
        device: PyTorch device
        max_items: Maximum items (for item-scoped variables)
    """
    self.variables = {v.id: v for v in variables}
    self.batch_size = batch_size
    self.max_items = max_items
    self.device = torch.device(device) if isinstance(device, str) else device

    # Existing: global_vfs, agent_vfs, agent_private_vfs...

    # NEW: Allocate item-scoped storage
    item_vars = [v for v in variables if v.scope == VariableScope.ITEM]
    if item_vars and max_items > 0:
        # item_vfs: [max_items, num_item_vars]
        self.item_vfs = torch.zeros(
            (max_items, len(item_vars)),
            dtype=torch.float32,
            device=self.device,
        )

        # Set default values
        for idx, var in enumerate(item_vars):
            if var.default is not None:
                if isinstance(var.default, (int, float)):
                    self.item_vfs[:, idx] = var.default
                elif isinstance(var.default, list):
                    # Vector defaults (if needed)
                    self.item_vfs[:, idx] = torch.tensor(var.default[0])

        # Map variable IDs to indices for item scope
        self.item_var_to_index = {v.id: idx for idx, v in enumerate(item_vars)}
    else:
        self.item_vfs = None
        self.item_var_to_index = {}
```
