## Rules of engagement (fail-forward)
- effect_manager and item_manager must be required in ExecutionContext; any missing wiring should crash immediately.
- Unsupported inputs (unknown collection, unsupported placement) must raise; no silent skips or fallbacks.
- No migration or compatibility layers; action/obs shifts are acceptable but should be noted in comments/tests.
- Keep changes in small patches; run a test after every file touched.

   - spawn_item placement: strategies self/target/explicit/random; collision + retry (e.g., 3 attempts); aspatial => raise; document helper name.
   - Cascade depth: set max depth (e.g., 10); raise when exceeded.

## Step-by-step tasks

### Task A: ExecutionContext sweep (mandatory prerequisite)
Goal: All call sites pass required managers; assertions catch stragglers.
- Edit `src/townlet/effects/context.py`: required fields (bars, vfs_registry, self_index, effect_manager, item_manager; target_index may be None). Keep assert/TypeError for missing managers.
- Update call sites one by one (use your caller list):
  - Env step loop (where ExecutionContext is built each tick).
  - Affordance engine / action handlers.
  - Item handlers or any effect execution helpers.
  - Tests constructing contexts (search in tests/).
- After each file update, run the smallest relevant test (example: `uv run pytest tests/test_townlet/unit/effects -k context` or specific module if known).
- Stop when the fast test suite no longer fails at construction due to missing managers.

### Task B: spawn_effect implementation
Goal: Replace stub; support targets, params, depth cap.
- Code changes (src/townlet/effects/executor.py):
  - Resolve target: "self" → self_index; "target" → target_index; int → explicit index; raise otherwise.
  - Enforce cascade depth cap using context.spawn_depth (add field if missing; default 0).
  - Call effect_manager.spawn_effect with effect_id, resolved target, duration, params.
  - Return real effect instance ID(s); no dummy values.
- Tests to create (tests/test_townlet/unit/effects/test_spawn_effect.py):
  - self target works; target target works.
  - Params (e.g., intensity, duration) propagate through.
  - Cascade chain A→B→C executes; depth cap triggers RuntimeError when exceeded.
  - Missing manager wiring raises (trigger via intentionally empty context in test).
- Quick integration smoke (add small fixture or reuse existing): affordance/item action that spawns another effect; assert spawned effect exists.
- Run: `uv run pytest tests/test_townlet/unit/effects/test_spawn_effect.py`

### Task C: spawn_item implementation
Goal: End-to-end item spawning with placement and initial_state.
- Code changes:
  - ItemManager (src/townlet/items/manager.py):
    - Add placement helper (e.g., find_spawn_location(origin, strategy, retries=3)): self/target/explicit/random; collision check; retry; raise if blocked or aspatial.
    - Extend spawn_item to accept initial_state (dict) and quantity; apply initial_state to item VFS; loop for quantity; return IDs.
  - Executor (src/townlet/effects/executor.py):
    - Parse item_id, position, quantity (default 1), initial_state.
    - Resolve position via placement helper using context.self_index/target_index for origins.
    - Fail on unsupported position or missing spatial data.
- Tests (tests/test_townlet/unit/effects/test_spawn_item.py):
  - self/target/explicit coords succeed.
  - random placement succeeds when space exists; raises when blocked after retries.
  - quantity > 1 returns multiple IDs.
  - initial_state applies (e.g., durability, quality fields set).
  - Unsupported position string raises; missing manager raises.
- Integration smoke (tests/test_townlet/integration/test_item_generation.py):
  - Effect on_despawn spawns an item; item appears at resolved position; pickup works (inventory slot occupied).
- Run: `uv run pytest tests/test_townlet/unit/effects/test_spawn_item.py`

### Task D: for_each implementation
Goal: Iterate collections with defined sources and caps.
- Code changes (src/townlet/effects/executor.py + new helper file if needed e.g., effects/collections.py):
  - Supported collections: nearby_agents (requires spatial query + radius), all_agents (agent registry), inventory_items (inventory slots of self/target), active_effects (from effect_manager for self/target).
  - Enforce iteration cap (configurable constant, e.g., 64); raise if exceeded.
  - Empty collections → no-op; unknown collection → raise.
  - Bind iterator variable in child context; body commands execute per element.
- Tests (tests/test_townlet/unit/effects/test_for_each.py):
  - nearby_agents respects radius (in/out cases).
  - all_agents iterates all.
  - inventory_items iterates only populated slots.
  - active_effects iterates current effects.
  - Unknown collection raises; iteration cap raises when exceeded.
  - Iterator binding usable in expressions (e.g., modify target via iterator alias).
- Integration smoke (tests/test_townlet/integration/test_aoe_effects.py):
  - AoE heal damages/repairs only in radius; outside agents untouched.
- Run: `uv run pytest tests/test_townlet/unit/effects/test_for_each.py`

### Task E: on_interrupt hook
Goal: on_interrupt fires on replace/merge/manual cancel before on_despawn.
- Code changes (src/townlet/effects/manager.py):
  - In reapply paths (replace/merge), detect interruption, call lifecycle executor for on_interrupt before removal.
  - Manual cancel routes should also invoke on_interrupt.
  - Pass interrupt_reason into ExecutionContext (field optional; keep required managers).
- Tests (tests/test_townlet/unit/effects/test_lifecycle_interrupt.py):
  - replace triggers on_interrupt then on_despawn (order check).
  - merge triggers on_interrupt when old effect consumed.
  - manual cancel triggers on_interrupt.
  - on_interrupt can spawn_effect successfully.
- Run: `uv run pytest tests/test_townlet/unit/effects/test_lifecycle_interrupt.py`

## Risks and how to avoid them
- Missed call sites → keep asserts in ExecutionContext until all tests pass; don’t remove early.
- No spatial API → explicitly raise in placement helper; do not silently place items.
- Random placement hangs in dense maps → cap retries (e.g., 3) and raise.
- Iterator collections undefined → raise with clear message; don’t default to empty silently.
- Ordering confusion for on_interrupt/on_despawn → enforce order in code and test it.

## Acceptance criteria per task (concrete)
- ExecutionContext sweep: All constructors pass both managers; asserts no longer trigger in any unit test; no default None parameters remain.
- spawn_effect: Depth cap enforced; real IDs returned; target resolution works; guard tests cover missing manager; cascade test passes.
- spawn_item: Placement respects strategies and collisions; initial_state reflected in item VFS; quantity > 1 yields multiple IDs; invalid strategy raises.
- for_each: Only supported collections; iteration cap enforced; iterator binding usable; empty collections no-op without error; unknown collection raises.
- on_interrupt: Fires before on_despawn on replace/merge/cancel; can run commands (including spawn_effect); reason plumbed.
- Integration: Items spawn via effects and can be picked up; AoE effects hit correct agents; cascades function end-to-end.

## Common pitfalls to avoid
- Adding optional defaults to ExecutionContext—don’t. Required means required.
- Swallowing errors in for_each or spawn_item; always raise on unsupported inputs.
- Forgetting to update tests that build ExecutionContext directly.
- Letting random placement loop forever; enforce retry cap.
- Running full test suite too late; run targeted tests after each file to catch small regressions early.
