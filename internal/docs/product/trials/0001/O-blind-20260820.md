## The idea, as frozen

> **O — Adversarial bidding**
> **Spec.** Agents bid against each other for a contested item; highest bid wins and pays.
> **Stresses.** A **global resolution phase over simultaneous agent submissions** — collect bids,
> compare, award, charge. Nothing else in the corpus needs the engine to run a clearing step. Sits
> in deliberate contrast with H: same contention problem, different clearing rule (first-come vs.
> highest-value), which isolates the rule as the variable.
> **Predict: FAIL, ABSENT.**

Honest caveats a comparer should weigh:

1. **`scope: global` on an effect is inert.** The clearing effect declares `scope: global` and
   validates, but `_execute_spawn_effect` (`src/townlet/effects/executor.py:222`) hardcodes
   `scope=EffectScope.AGENT`, so it attaches to an agent slot instead. Probe output:
   `global_effects: []` / `agent_effects: {0: ['auction_clearing']}`. The pack works because it
   pins the clearing to `target: "0"` and the body is agent-agnostic, but the *declared* global
   phase is an emulation. Gap **G-6** — this is an INERT declarative surface in its own right,
   though it did not fail any facet of idea O.
2. **The clearing must be ignited by an agent action.** No config surface spawns an effect at
   episode start, so `BID_LOW`/`BID_HIGH.on_start` each spawn the clearing effect
   (`reapply_policy: renew`, long duration) to start it. Until some agent bids once, no clearing
   phase exists. Gap **G-7**.
3. **`prize_holder` came from a scan-counter idiom, not a first-class argmax** (G-4), and the
   whole design leans on the `all_agents` for-each, which is undocumented (G-8, doc defect). A
   side effect worth naming for anyone who promotes this pack to a fixture: the G-4 workaround
   variable `scan_index` is a loop counter, and because every global-profile variable compiles to
   its own observation field it now occupies observation dim `[137:138]` and is fed to the policy.
   It carries no meaning to an agent (it reads `3.0` — the agent count — at every observation);
   it is scaffolding the engine forced into the tensor, not designed state.
4. All evidence is single-step behavioral read-back. No training run was performed; whether an
   agent *learns* to bid adversarially is out of the protocol's scope and is not claimed.
